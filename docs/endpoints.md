## Binary Streaming Protocol (Message Code 13)

Fixed 215 Hz, binary packets sent automatically during active streaming.

**Packet Structure** (108 bytes total):

| Offset | Size | Field | Description |
|--------|------|-------|-------------|
| 0 | 1 byte | `magic` | Start marker: `0xAA` |
| 1 | 1 byte | `message_code` | Always `0x0D` (13) |
| 2 | 4 bytes | `timestamp` | `millis()` value, little-endian `uint32_t` |
| 6 | 2 bytes | `sample_count` | Number of samples, little-endian `uint16_t` (typically 50) |
| 8 | 100 bytes | `samples[]` | 50 × `int16_t` values, little-endian |

**Data conversion**: `voltage_mV = sample_int16 / 1.0` (1 LSB = 1 mV)

**Bandwidth**: 464 bytes/s (~4.3 packets/sec), 48% of 9600 baud capacity.

## Session Parameters Payload (Code 7)

```json
{
  "a": 3.0,     // Amplitude (volts) → Potentiometer
  "f": 38.0,    // Frequency (Hz) → FES pulse frequency
  "pw": 12.0,   // Pulse width (µs) → FES pulse duration
  "df": 5,      // Difficulty (1-100%) → sEMG trigger threshold
  "pd": 5       // Stimuli duration (seconds) → FES on-time
}
```
