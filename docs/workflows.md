## 4. sEMG Trigger Detection Pipeline

```mermaid
sequenceDiagram
    participant Timer as Sampling Timer (ISR)
    participant Buf as raw_value[] buffer
    participant Filter as SemgFilter
    participant Thresh as Threshold Check
    participant FES as Fes::fesLoop
    participant BT as Bluetooth TX

    loop Every 4ms (250 Hz sampling)
        Timer->>Buf: ADC read → raw_value[i]
        Note over Timer: Increments sample_amount
    end

    Note over Buf: When sample_amount >= 50
    Buf->>Filter: filterSamplesArray()
    Filter->>Filter: Butterworth bandpass (10-50 Hz)
    Filter->>Thresh: RMS of filtered samples

    alt RMS > threshold
        Thresh->>BT: sendTriggerMessage (Code 9)
        Thresh->>FES: fesLoop()
        FES->>FES: Biphasic pulses via H-bridge
        Note over FES: positiveHBridge → negativeHBridge → reset
        FES-->>Thresh: Stimulation complete
    else RMS <= threshold
        Thresh->>Thresh: Continue sampling
    end
```

```mermaid
    ADC->>ADC: xTaskCreatePinnedToCore(adcTaskLoop)
    SEMG->>Task: xTaskCreatePinnedToCore(streamingTask)
    MH->>App: {"cd":11,"mt":"a"} (ACK)

    loop Every ~4.65ms (215 Hz)
        ADC->>ADC: Read ADS1115 (860 Hz, 4x downsample)
        ADC->>ADC: Write to circular_buffer[512]
    end

    loop streamingTask polling
        Task->>ADC: hasNewSample()?
        ADC-->>Task: int16_t sample
        Task->>Task: Apply Butterworth + Notch filter
        Task->>Task: Buffer 50 samples
        Task->>BT: sendBinaryStreamingMessage (108 bytes)
        BT->>App: Binary packet [0xAA][0x0D][ts][count][data...]
    end

    App->>MH: {"cd":12,"mt":"x"}
    MH->>SEMG: disableStreaming()
    SEMG->>ADC: stopContinuousMode()
    SEMG->>Task: vTaskDelete
    MH->>App: {"cd":12,"mt":"a"} (ACK)
```

## 6. FES Biphasic Pulse Generation

```mermaid
sequenceDiagram
    participant Session as Session Task
    participant FES as Fes::fesLoop
    participant HB as H-Bridge GPIO
    participant Pot as Potentiometer
    participant Safety as Safety Checks

    Session->>FES: fesLoop()
    FES->>Pot: voltageSet(amplitude)
    FES->>Pot: getCorrectedVoltage()
    Pot-->>FES: measured voltage
    FES->>Safety: |voltage - target| < 0.5V ?

    alt Voltage OK
        loop duration_ms elapsed
            FES->>Safety: emergency_stop?
            alt Emergency
                FES->>HB: hBridgeReset()
                FES-->>Session: Abort
            end
            FES->>HB: positiveHBridge()
            Note over HB: delayMicroseconds(pulse_width)
            FES->>HB: negativeHBridge()
            Note over HB: delayMicroseconds(pulse_width)
            FES->>HB: hBridgeReset()
            Note over HB: Wait remaining period
        end
    else Voltage Error
        FES->>FES: Log error, abort
    end
    FES-->>Session: Stimulation complete
```
